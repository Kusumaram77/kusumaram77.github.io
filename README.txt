Files:

- assets/kusuma-profile.jpg: cropped profile photo

PUBLISH ON GITHUB PAGES:
1. Open https://github.com/kusumaram77
2. Open the repository you created. Its name should be kusumaram77.github.io
3. Upload BOTH index.html and the assets folder (with kusuma-profile.jpg inside).
   On the repository page, choose Add file > Upload files.
4. Drag index.html and the assets folder into the upload area, then commit changes.
   If folder upload does not work in your browser, create the assets folder first and
   upload kusuma-profile.jpg inside it, then upload index.html to the repository root.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch; select main and / (root),
   then Save.
7. Wait a few minutes, then open https://kusumaram77.github.io
